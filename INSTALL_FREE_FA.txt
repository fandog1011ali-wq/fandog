راهنمای نصب رایگان TITAN 4.1.1 روی GitHub Pages + Cloudflare Workers Free
================================================================================

این بسته برای اجرای رابط TITAN روی GitHub Pages و عبور دادن استریم‌های HTTP/HTTPS
از یک آدرس HTTPS ساخته‌شده با Cloudflare Workers است. برای شروع نیازی به خرید دامنه،
VPS، هاست PHP یا ارتقای Workers به پلن پولی نیست.

بخش ۱ ـ انتشار سایت روی GitHub Pages
-------------------------------------
مخزن فعلی شما:
https://github.com/fandog1011ali-wq/fandog

1) محتوای این ZIP را در ریشه مخزن استخراج کنید.
2) فایل‌های هم‌نام را جایگزین و پوشه‌های موجود را حفظ کنید.
3) همه فایل‌های پروژه، از جمله پوشه playlists و فایل‌های assets را Commit کنید.
4) GitHub Pages باید از main و /(root) منتشر شود.
5) آدرس سایت:
   https://fandog1011ali-wq.github.io/fandog/

بخش ۲ ـ ساخت Worker رایگان
---------------------------
1) وارد https://dash.cloudflare.com شوید و یک حساب بسازید یا وارد شوید.
2) از منوی Workers & Pages گزینه Create application / Create Worker را بزنید.
3) نام Worker را titan-stream-proxy بگذارید.
4) Worker اولیه را Deploy کنید.
5) پس از ساخت، Edit code را باز کنید.
6) کل کد فایل cloudflare-worker/worker.js را جایگزین کد پیش‌فرض کنید.
7) Deploy را بزنید.
8) URL عمومی workers.dev را از صفحه Worker بردارید. نمونه:
   https://titan-stream-proxy.YOUR-SUBDOMAIN.workers.dev

نکته: از Workers Free استفاده کنید. پلن پولی را انتخاب نکنید و برای این پروژه دامنه
اختصاصی خریداری نکنید. فایل wrangler.jsonc نیز برای اجرای اختیاری با Wrangler همراه بسته است.
این نسخه برای IPها و پورت‌های سفارشی از TCP sockets استفاده می‌کند و به پرچم allow_custom_ports
نیاز ندارد؛ بنابراین تنظیم Compatibility flag اضافی لازم نیست.

بخش ۳ ـ وصل کردن پلیر به Worker
-------------------------------
1) در GitHub مخزن fandog را باز کنید.
2) فایل worker-config.js را باز کنید و Edit را بزنید.
3) فقط مقدار URL را با URL واقعی Worker خود جایگزین کنید. نمونه:

   window.TITAN_WORKER_URL = 'https://titan-stream-proxy.YOUR-SUBDOMAIN.workers.dev';

4) Commit changes را بزنید و منتظر انتشار Pages بمانید.
5) ابتدا این نشانی را با دامنه واقعی Worker باز کنید:

   https://YOUR-WORKER-URL/health

6) پاسخ باید JSON با ok:true باشد.
7) سایت TITAN را با Ctrl+Shift+R تازه‌سازی کنید.

بخش ۴ ـ تست
------------
- ابتدا /health را تست کنید.
- یک شبکه HTTP را انتخاب کنید.
- در صورت خطا، متن دقیق خطای Worker/پلیر را بررسی کنید.
- اگر Worker خطای host not allowed داد، منبع در allowlist نیست. فقط دامنه/IP متعلق
  به منبعی را که مجاز به استفاده از آن هستید به HOST_PORTS یا IP_PORTS اضافه کنید.

محدودیت‌های واقعی نسخه رایگان
------------------------------
- سهمیه Workers Free طبق مستندات جاری Cloudflare: 100,000 درخواست ورودی در روز.
- CPU مجاز: 10 میلی‌ثانیه برای هر درخواست Worker.
- تعداد subrequest مجاز: 50 برای هر فراخوانی.
- حداکثر شش اتصال خروجی هم‌زمان در مرحله انتظار برای پاسخ.
- هر دریافت قطعه HLS، زیرپلی‌لیست یا فایل رسانه از مسیر Worker می‌تواند یک درخواست ورودی
  جداگانه باشد؛ تماشای طولانی یا کاربران متعدد ممکن است سهمیه روزانه را مصرف کند.
- Worker تبدیل کدک/FFmpeg انجام نمی‌دهد و پهنای‌باند منبع اصلی را رایگان نمی‌کند؛ فقط
  درخواست HTTP را از سمت سرور Worker عبور می‌دهد. محدودیت‌های سهمیه و منبع پابرجاست.

مواردی که حل نمی‌شوند
---------------------
- RTSP، RTMP، UDP، SRT و پروتکل‌های غیر HTTP/HTTPS از این پراکسی HTTP عبور نمی‌کنند.
- تبدیل HEVC/AV1/کدک ناسازگار به H.264/AAC با Worker انجام نمی‌شود.
- اگر ارائه‌دهنده استریم، IPهای Cloudflare را مسدود کرده باشد یا ورود/کوکی/توکن معتبر
  لازم داشته باشد، Worker نمی‌تواند مجوز منبع را دور بزند.
- لینک‌هایی که مقصدشان IP خصوصی، localhost یا بازه‌های مسدودشده Cloudflare باشد کار نمی‌کنند.
- CORS و محدودیت‌های منطقه‌ای یا قراردادی ارائه‌دهنده همچنان اعمال می‌شوند.

امنیت
------
- این Worker یک پراکسی باز برای همه اینترنت نیست؛ فقط میزبان‌های ثابت فهرست‌شده در
  HOST_PORTS و IP_PORTS را قبول می‌کند.
- اگر پلی‌لیست‌های عمومی حاوی URLهای دارای رمز/توکن هستند، آن توکن‌ها را عمومی نکنید؛
  توکن‌های افشاشده را تعویض کنید.
- مخزن GitHub شما Public است. هیچ رمز، توکن ربات یا اطلاعات ورود را داخل آن نگذارید.

فایل‌های مهم
------------
cloudflare-worker/worker.js       کد کامل Worker
cloudflare-worker/wrangler.jsonc تنظیمات اختیاری Wrangler
worker-config.js                 محل وارد کردن URL واقعی Worker
modern.html / legacy.js          نسخه‌های متصل‌شده به Worker
playlists/*.m3u                  چهار فهرست کانال
