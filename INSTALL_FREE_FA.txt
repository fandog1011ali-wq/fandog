راهنمای رایگان TITAN 4.1.4
===========================

1) Worker یا دامنه پولی لازم نیست برای منابعی که HTTPS قابل پخش دارند.
2) فایل‌های modern.html، legacy.js و sw.js را در ریشه مخزن GitHub جایگزین کنید.
3) پس از انتشار Pages، با Ctrl+Shift+R کش مرورگر را تازه کنید.
4) کانال HTTP در صورت امکان ابتدا از طریق HTTPS همان میزبان آزمایش می‌شود.
5) اگر پخش نشد، از دکمه «باز کردن لینک اصلی در تب جدید» استفاده کنید.

محدودیت فنی:
- اگر سرور فقط HTTP داشته باشد، مرورگر در صفحه HTTPS اجازه پخش درون‌صفحه‌ای نمی‌دهد. برای این حالت پراکسی HTTPS واقعی لازم است.
- اگر سرور CORS را ببندد، HLS.js/DASH.js نمی‌توانند playlist/segment را بخوانند؛ ارائه‌دهنده باید CORS را فعال کند یا Worker/پراکسی لازم است.
- کدک ناسازگار بدون FFmpeg/تبدیل سرور قابل تبدیل نیست.
