گزارش اصلاح و آزمون TITAN 4.1.3
================================

منبع پروژه:
- بسته کامل TITAN 4.1.2_WORKER_MERGED
- فایل worker.zip ارسالی کاربر (Telewebion manifest rewriter)

علت اصلی خطای پخش در نسخه قبلی:
1) در modern.html مقدار mixed||IS_STATIC_PAGES به مسیر HLS داده می‌شد؛ یعنی روی GitHub Pages حتی HLSهای HTTPS نیز به Worker اجباری هدایت می‌شدند.
2) فایل worker-config.js آدرس Worker نداشت؛ بنابراین تمام تلاش‌های پراکسی با خطای آدرس Worker خالی متوقف می‌شد.
3) در حالت DASH، MPEG-TS/FLV، فایل مستقیم و مسیر ناشناخته نیز چند شرط، پراکسی را برای همه منابع GitHub Pages اجباری می‌کرد.

اصلاحات 4.1.3:
- HLS در صفحات GitHub ابتدا مستقیماً از منبع HTTPS پخش می‌شود.
- HLS فقط برای HTTP/Mixed Content یا خطای شبکه/CORS به Worker اختیاری مراجعه می‌کند.
- DASH، MPEG-TS، FLV و فایل‌های مستقیم نیز برای منبع HTTPS ابتدا مستقیم امتحان می‌شوند.
- در حالت نبود Worker، لینک HTTP پیام خطای روشن می‌دهد و تلاش مبهم برای پراکسی خالی انجام نمی‌شود.
- برای منابع HTTPS که CORS ندارند، خطای محدودیت مرورگر توضیح داده می‌شود؛ این محدودیت با HTML/JavaScript در GitHub Pages قابل دور زدن نیست.
- نسخه Legacy نیز برای HTTPS ابتدا پخش مستقیم را امتحان می‌کند و فقط HTTP را به Worker ارجاع می‌دهد.
- نسخه کش Service Worker از v410 به v413 تغییر کرد تا فایل‌های قدیمی کمتر باقی بمانند.
- Worker عمومی TITAN و مسیر اختصاصی Telewebion در بسته کامل حفظ شده‌اند.

- مجموع URLها: 678
- HTTP: 542
- HTTPS: 136
- 42 میزبان دامنه‌ای و 25 IP یکتا در منابع M3U دیده شد.
- allowlist Worker شامل همه میزبان‌ها و پورت‌های همین 678 URL است.

محدودیت‌های مهم و صادقانه:
- آدرس worker-config.js عمداً خالی است؛ Worker داخل GitHub Pages اجرا نمی‌شود و فقط پس از Deploy در حساب Cloudflare قابل استفاده است.
- بدون Worker/پراکسی HTTPS، لینک‌های HTTP روی سایت HTTPS توسط مرورگر مسدود می‌شوند.
- لینک‌های HTTPS نیز فقط وقتی در مرورگر قابل پخش‌اند که منبع پاسخ مناسب و CORS لازم را بدهد و کدک آن توسط دستگاه پشتیبانی شود.
- در محیط ساخت دسترسی DNS/شبکه به ارائه‌دهندگان استریم وجود نداشت؛ بنابراین پخش زنده واقعی هر 678 لینک قابل آزمایش نبود.
- Worker/Pages نمی‌توانند RTSP/RTMP/UDP/SRT یا کدک ناسازگار را بدون سرویس تبدیل رسانه به HLS/MP4 تبدیل کنند.

امنیت:
- فایل cache هویتی .wrangler از بسته خروجی کپی نشده است.
- error_log runtime در بسته عمومی قرار نگرفته است.
