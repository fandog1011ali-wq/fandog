TITAN IPTV Player 4.1.4
=======================

این نسخه کامل پروژه قبلی را حفظ می‌کند و یک مسیر رایگان best-effort اضافه می‌کند:
- لینک‌های HTTPS مستقیم پخش می‌شوند.
- اگر لینک پلی‌لیست HTTP باشد و Worker تنظیم نشده باشد، نسخه HTTPS همان URL به‌صورت خودکار امتحان می‌شود. پورت 80 به 443 نگاشت می‌شود و پورت سفارشی حفظ می‌شود.
- اگر HTTPS روی همان میزبان فعال باشد و CORS/کدک اجازه دهد، پخش بدون ساخت سرویس اضافی ممکن است.
- در صورت شکست، لینک اصلی در تب جدید قابل بازکردن است.
- Worker اختیاری همچنان برای لینک‌های HTTP فاقد HTTPS یا منابع CORS-محدود لازم است.

نکته: هیچ کد جاوااسکریپتی نمی‌تواند یک سرور HTTP-only را به HTTPS واقعی تبدیل کند یا محدودیت CORS مرورگر را دور بزند. پس این نسخه تضمین پخش تمام منابع را نمی‌دهد.

برای GitHub Pages، فایل‌های modern.html، legacy.html، legacy.js و sw.js را در ریشه مخزن جایگزین کنید. فایل GITHUB_PAGES_PATCH_4.1.4_FA.txt راهنمای کوتاه اعمال Patch است. پوشه playlists و assets را دست نزنید.
